One-Liner Marathon

A comedy entry for the make.fun One-Liner Marathon competition. The joke plays on the modern ritual of muting a group chat — the setup promises relief and quiet, but the punchline flips it: the silence wasn't peace at all, it was everyone else finally getting to finish a sentence. The turn reframes personal tranquility as a group communication breakthrough, landing on a wry observation about how we talk over each other.

Run with `node main.ts` — it writes the entry to `/output/entry.txt`.
